# DSA Tracker

A modern and interactive Data Structures & Algorithms (DSA) progress tracking platform built with Next.js, TypeScript, and Tailwind CSS.

## Features

* 📚 Roadmap-based DSA learning plan
* ✅ Track solved problems
* 🔥 Daily streak system
* 🎯 Daily goal tracking
* 📊 Weekly and monthly analytics
* 📈 Progress dashboard
* 🔍 Search problems instantly
* 💾 Local storage persistence
* 🌙 Modern responsive UI
* 🚀 Built for coding interview preparation

## Tech Stack

* Next.js
* TypeScript
* React
* Tailwind CSS
* Framer Motion

## Purpose

This project helps students and developers stay consistent with DSA practice by tracking progress, maintaining streaks, analyzing performance, and following a structured roadmap to crack coding interviews and placement exams.
